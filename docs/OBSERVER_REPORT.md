# 観測専用版 完成報告（2026-11-21）

実行物：`dist/Onecarat-CX.exe`。Windowsで起動し、既存の実Codexログの更新をキャラクターに反映するところまで実装・確認した。承認待ちとサブエージェントは合成ログ検証のみで、実機取得を確認済みとは扱わない。

## 1. 完成した機能

Windowsネイティブ小窓、思考・ツール・編集・実行・応答等の動き、明示的ターン終了時の手振り、セッション切替、明示的な親子関係に基づく追加キャラクター、最前面切替、アニメーション停止、最小化・サイズ変更、日本語・英語、時間帯による窓外の配色。無更新や観測障害では状態不明に戻す。設定・履歴・本文の永続保存、Codexへの操作機能はない。

## 2. アーキテクチャと理由

Node.jsの標準ファイルAPIで既存ログをread-only tailし、固定フィールドだけをstdout pipeでC# Windows Formsへ渡す。GDI+でキャラクターを描画。HTTPサーバー・WebView・外部パッケージを使わず、既存Codexへ接続や操作をしない。現在の製品には旧CXの操作用ランタイム・Research Labを組み込まない。詳細は[設計](OBSERVER_DESIGN.md)。

## 3. イベント取得方式

`CODEX_HOME/sessions`、未設定なら通常ユーザーの`.codex/sessions`。別配置は`CX_SESSIONS_DIR`で指定できる。JSONLのsession_meta、event_msg、response_itemをallowlistで変換する。750ms読取、3秒探索、64ログ上限。起動時は直近24時間更新のログだけ。会話本文は読み取りバッファに一時的に入るが、表示プロセスへの転送・表示用保持・保存はしない。

app-serverの新規セッション操作と既存セッション観測を区別し、旧成功結果は今回の実機検証に転用していない。公式ガイドのthread/readは購読ではないため、本製品ではapp-serverの起動・read・resumeを行わない。

## 4. 観測できる情報・できない情報

| 区分 | 情報 |
|---|---|
| 実ログ構造を確認 | 開始・ターン終了・中断、思考、応答、コマンド実行・編集等のitem_completed、ツール呼び出し |
| 現在の開発セッションで追記を確認 | 編集、作業イベント。ネイティブ小窓でも実ログのツール等を描画 |
| 実機取得は未確認 | 承認要求、子セッションの明示的parent ID。それらの合成ログ→画面は確認済み |
| 表示しない／不明 | 成功率・進捗率、成果の正しさ、実行中プロセスの生存、無更新の理由、セッション終了、exec内のツール内容、保存されないログ、別PC・Cloudの活動 |

「直近の観測」は記録があったことを表す。item_completed後も「コマンド実行」のしぐさを短時間表示するが、コマンドが現在も実行中とは断定していない。15秒無更新で不明にする。ターン終了は成功やセッション終了を意味しない。

## 7. 制約・既知の問題

- ログ形式は安定APIではない。確認した版以外、保存無効、リモートセッションは保証しない。
- 承認待ちがログに出ない場合は検出できない。承認は常にCodex側を確認する。親子情報がなければ子キャラクターを捏造しない。
- 記録遅延がある。15秒無更新なら、長時間実行中でも不明になる。最近使ったセッションと現在起動中の区別はできない。
- 1行512KiB超、古いログ、上限超過等は省略する。全活動の完全な再現は目的にしない。
- 1窓内の切替方式。通知音・タスクバー点滅・自動起動登録・設定保存・配布パッケージは作らない。署名・公開・配布は未実施。
- 高DPIや複数モニター、長時間連続運用・極端なログ数での実機耐久検証は未実施。

## 8. 起動方法

`dist/Onecarat-CX.exe`をダブルクリック、または開発先で`npm.cmd start`。NodeがPATHにない場合はNode.js 24以上を利用可能にするか、`CX_NODE_EXE`に既存node.exeの絶対パスを指定する。通常起動は追加パッケージ・ビルド不要。

## 10. 主な自律判断

観測専用要件から、旧操作系を製品から外し、既存ログの受動読み取りを採用した。承認・子情報の未検証部分を架空表示で埋めず、取得できないものは不明とした。追加依存なしのネイティブ描画、IDのみの匿名的な表示名、設定非保存、1窓の切替を選び、軽量性と情報最小化を優先した。旧コード・プローブ・消費済みマーカーは履歴として保持した。判断は[DECISIONS](DECISIONS.md)に日付と根拠を記載。
