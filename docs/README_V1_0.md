# Onecarat Agent Office CX

**Codexが働く姿を、小さなオフィスで楽しく眺める。** Windows用の観測専用アプリです。Codexへの入力・承認・拒否・設定変更の経路はありません。

## 起動

Windows 10/11、.NET Framework 4.8、Node.js 24以上を使用します。このPC向けにビルド済みです。

**`dist/Onecarat-CX.exe` をダブルクリック**してください。通常のPowerShellからは次でも起動できます。

```powershell
Set-Location C:\work\onecarat-agent-office-cx
npm.cmd start
```

いつものCodex CLIで作業すると、既存ログの追記がキャラクターに反映されます。CLIの再設定・フック追加・ログイン・モデル送信は不要です。小窓を閉じると、その小窓が起動した観測プロセスも終了します。Codexは終了しません。

## 小窓の使い方

- セッション欄：表示するセッションを選択。末尾8文字のIDで区別します。会話タイトルや作業フォルダ名は取り込みません。
- `● / ○`：最前面表示の切替。初期値は最前面です。
- `Ⅱ / ▶`：アニメーションの停止・再開。観測は継続します。
- `EN / 日本語`：言語切替。初期値はWindowsのUI言語です。
- 通常のタイトルバーで移動・サイズ変更・最小化・終了できます。設定は保存しません。

「直近の観測」はログに記録された活動です。ツールの内部ではなく、記録された種別を表します。15秒間新しい対応イベントがない場合は「現在の状態は不明」として動作を止め、最終記録と時刻を表示します。**無更新は、作業終了・承認待ち・停止の証拠ではありません。** ターン終了は成功判定でもセッション終了でもありません。

## 観測の範囲

既定では `%USERPROFILE%\.codex\sessions` を読み取り専用で監視します。`CODEX_HOME` が設定されていれば、その `sessions` を使います。起動時点で24時間以内に更新されたログ、および起動後に更新されたログを最大64件表示します。

```powershell
# 別のローカルログ配置を観測する場合。このプロセスだけへの指定です。
$env:CX_SESSIONS_DIR = 'D:\my-codex-home\sessions'
npm.cmd start
```

確認済み環境はCodex CLI 0.169.0です。ログは公開された安定APIではなく、将来形式が変わる場合があります。ログを保存しないセッション、別PC・クラウド、別Windowsユーザーは対象外です。

承認待ちはログへの記録を実機で確認できていません。明示的な承認要求イベントが存在するときだけ表示し、**承認の確認はCodex側で行ってください**。サブエージェントも明示的な親子関係のあるログだけで描画します。実機での親子表示は未検証です。

## データと安全性

ログは本文も含むJSONLなので、読み取りバッファには本文が一時的に入ります。表示へ渡すのはID、親ID、活動種別、記録時刻、CLIバージョン、観測件数だけです。本文・コマンド・ファイル名・ツール結果・認証情報を表示用に保持・転送・保存しません。ネットワーク待受・外部通信・観測データの永続保存はありません。

## ビルドとテスト

追加パッケージのインストールは不要です。ビルドはWindows付属のC#コンパイラを使います。

```powershell
npm.cmd run build
npm.cmd run test:observer
npm.cmd run test:desktop
npm.cmd run check
```

`test:desktop` は合成ログで実Windowsウィンドウを開き、自動操作・スクリーンショット・終了確認を行います。実Codexの承認やモデルを操作するテストではありません。出力は `.cx/observer-tests` と `artifacts/observer` に限定しています。
