## 4. 最終受け入れと記録方法

各段階のレポートは「実装済み」「モック確認済み」「実機確認済み」「未確認」を別列にする。テスト名/fixture版/実行環境/実行日時/結果/禁止操作カウントを保存する。UIスクリーンショットにはMOCK表示を含める。失敗をskipで隠さず、修正前の再現と修正後の回帰を記録する。

段階のPASSはその承認範囲だけに適用する。フェーズ1の条件付きPASSやR1〜R4を自動解除しない。Phase2モック完成を、Research Lab/秘書の実サービス提供や初回正式公開完成と表現しない。
