# 動き・承認表示のプレビュー

2026-11-22、作者の「親子の様々な動きと承認待ちを見たい」という依頼により追加。

通常のPowerShellで次を実行する。起動中のOfficeを閉じる必要はない。

```powershell
& C:/work/onecarat-agent-office-cx/dist/preview/Office-Motion-Preview.exe
```

これは「表示テスト」とタイトル・画面上部に明記した合成データの別アプリ。Codexも監視workerも起動せず、実ログを作成・変更しない。承認や拒否の操作は行わない。普段のOfficeランチャーの行先は変更していない。

65秒周期で思考5秒、調査5秒、編集5秒、コマンド5秒、子2体の参加・委任6秒、承認表示20秒、合成上の解除と報告7秒、終了12秒を表示する。承認要求から15秒を過ぎると解決状況不明へ変わり、色と要求履歴は残る。46秒時点の解除はシナリオの合成状態であり、実際の利用者による承認ではない。×で終了するまで繰り返す。

現行Codexの実ログで承認要求を確実に取得できない制約は変わらない。このプレビューの成功を実承認検出の成功とは扱わない。

ビルド：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-motion-preview.ps1`。

検証：専用EXEの`--verify`で10時点を撮影し、承認表示・15秒後の不明表示・合成解除を確認した。保存先はartifacts/motion-preview。これは時間を進めた合成試験であり、通常デスクトップでの65秒ループを利用者が見たという意味ではない。別途、実際に子2体へコード確認とv1.1テストを委任し、11件成功の報告を受領した。
