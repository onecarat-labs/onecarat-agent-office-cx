# フェーズ2 Office・Research Lab モック実装結果

2026-11-15。今回の作者承認範囲の画面レビュービルド。**実サービス提供版ではない**。フェーズ1は条件付きPASSのまま。秘書・認証変更・実モデル・実Thread・無人実行・外部連携・永続保存・時刻指定実行は実装していない。

## 起動・確認手順

```powershell
Set-Location C:\work\onecarat-agent-office-cx
npm run demo:phase2
```

端末に表示されたloopback URLをブラウザで開く。Node 24以上、追加依存不要。Codexのインストール/ログインはこのモックには不要。停止は起動端末のCtrl+C。画面状態はページのメモリにのみ保持され、再読込/タブを閉じると消える。別タブは別の独立fixtureコンテキストとなり、データ共有をしない。

1. Research Labでテーマ名・質問を入力して追加。複数テーマを作成可能。
2. 希望完了日時はタイムゾーン付きISO文字列、未入力も可。表示用の仮解釈で、期限が過ぎても何も実行しない。
3. 通常/0件/10件/11件異常/失敗/結果不明からシナリオを選び「モック調査を開始」。Officeに同じJobの作業中表示が出る。
4. 「成果受領イベントを進める」でカード受領。ここでは完了扱いしない。「完了イベントを進める」で選択シナリオの最終状態へ進む。取消も可能。
5. 出典・担当・不確実性を確認し、カードをレビュー/上下移動/アーカイブ/復帰。深掘りは追加質問で別runを作り、元カードの束に関連する。
6. 束表示と実行履歴を切替える。保存プレビューは文字列表示のみで、ファイル生成/ダウンロードはしない。
7. 表示設定で人物・背景の仮の2種を選択する。活動状態・権限・人物数は変わらない。

## 実装構成・設計からの具体化

| ファイル | 役割 |
|---|---|
| ui2/domain.mjs | メモリ状態、Job/run/card/関連、epoch/revision、操作ID重複抑止、失敗時の非変更、上限、fixture進行 |
| ui2/app.mjs、index.html、style.css | Office/Lab/外観、全てtextContentによる入力表示、レスポンシブ、下書きの画面間保持 |
| src/phase2-server.mjs | 127.0.0.1だけの静的GET配信。POST/APIなし。Runtime/Codex/child_processをimportしない |
| tests/phase2.test.mjs | 17件の基盤/HTTP/隔離テスト |
| scripts/phase2-ui-check.mjs | 22項目のブラウザ検証、デスクトップ/モバイル画像 |
| package.json、scripts/check.mjs | demo:phase2とui2構文検査 |

未承認の保存や認証変更を避けるため、設計の将来HTTP業務APIを今回作らず、純粋なブラウザ内ドメインを採用した。静的サーバーには利用者の質問/カード内容が送られず、認証・状態操作APIもない。既存フェーズ1のHTTP/RPC/認証境界は変更していない。将来共有状態が必要なら、このモックをそのまま多利用者サーバーに昇格させず再設計する。

Codexへの経路、fetch/WebSocket、永続ストレージ、定期タイマーはブラウザ側にない。CSPのconnect-srcはnone。画像・任意URL・ファイルの読込口もない。実Thread IDとのbindingは作らない。モックJob/runのIDは実Threadとは異なる内部ID。

操作はepoch/expectedRevision/operationIdを照合し、状態を複製して検証後に一括反映する。古い操作や不正入力は変更しない。重複操作の応答キャッシュは最大2000件、イベントは直近200件。ネットワーク越しのexactly-onceを保証するものではない。外部イベント購読や自動キューは未実装で、手動fixture操作が唯一の進行源。

先に共通基盤13件を通し、その後UIを追加。日時の実在日付検査と入力下書き保持、隔離テストを追加して最終結果を確認した。

- `node scripts/check.mjs`：成功。
- フェーズ2UI：**22項目成功**。[結果](../artifacts/phase2-ui-result.json)。Office空/進行、テーマ追加/編集/切替、下書き保持、過去時刻でも自動開始0、カード件数、深掘り/束、レビュー/アーカイブ/取消、各異常シナリオ、プレビュー、外観、再読込消去、HTML非実行、ページ例外0。
- 既存フェーズ1UI：**29項目成功**、実モデル0。既存コードに回帰がないことをモックで確認。
- ブラウザ要求は自身のloopback静的GETのみと検査。POST/外部要求なし、localStorage/sessionStorage空。静的import/禁止能力の検査も実施。固定modelCalls=0という結果値だけを根拠にしていない。
- デスクトップと390px幅を画像で確認。横スクロールなし。画像：[Office](../artifacts/phase2-office-desktop.png)、[Lab](../artifacts/phase2-lab-desktop.png)、[mobile](../artifacts/phase2-lab-mobile.png)。すべて架空データ。
- テストのブラウザ/ローカルサーバーは終了済み。実Codex起動・実モデル送信・実Thread作成・実認証・実承認操作は0。
- フェーズ1成功E2Eのconsumed.json、run-1yNyRR/result.json、office.pngのSHA256はPHASE1_POLISH記載値と一致。変更なし。CC版は既存Playwrightの読み取り参照だけで、書き込んでいない。
